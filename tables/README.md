# Table-ready frozen outputs

These CSV files are copies of aggregate table sources from the authoritative frozen PAPER008 research package. They are provided for manuscript traceability and do not replace the more detailed author-side audit archive.

The manuscript deliberately preserves mixed findings: AGRR is not described as universally superior, BBBP shuffled-rule controls remain competitive, and the principal AGRR ensemble is not capacity-matched to every comparator.
