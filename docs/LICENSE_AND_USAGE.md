# License and Usage Notes

## Software-code status

The authoritative research archive contains an internal `LICENSE_CODE.txt` stating an intention to release original study code under the MIT License. Before public deposition, however, the package audit also requires the authors to confirm ownership/provenance of all code and third-party components.

Because that confirmation is a legal/provenance decision that cannot be inferred from the files alone, this public repository currently **does not assert a repository-wide open-source license**. In the absence of an explicit license, normal copyright applies to original repository content.

If the authors confirm that all original study code can be permissively relicensed, adding a standard MIT `LICENSE` file would be consistent with the stated internal release intention.

## Third-party dependencies

Python packages listed in the environment retain their own licenses. This repository does not sublicense them.

## Datasets

Raw third-party datasets are not redistributed. Source links, provenance, and checksums are provided instead. Users must comply with the terms of the respective data providers.

## Manuscript and figures

The submitted manuscript is intentionally not stored in this repository. Publication rights for the article will follow the journal/publisher agreement.
